## Proyecto destacado · Jarvis

**Un asistente personal para hacer preguntas, gestionar recordatorios y trabajar con archivos utilizando modelos locales.**

Lo inicié para tener un asistente propio y mayor control sobre cómo se maneja mi información. Sus funciones locales pueden trabajar sin Internet; las búsquedas web necesitan conexión.

[![Vista de Jarvis](https://raw.githubusercontent.com/Diego-Git09/Jarvis/main/docs/imagenes/jarvis-demo.png)](https://github.com/Diego-Git09/Jarvis)

**Python · Ollama · Tkinter**

Participé en la definición de funciones, las pruebas de respuestas, las mejoras de vocabulario, la interfaz y el soporte de documentos y varios archivos a la vez. Utilicé asistentes de IA para generar y modificar código.
